## Built with Security at the Core

AdminDroid AI Assistant is designed to keep your organizational data protected at every step.

### Confirmation before action
All queries request explicit confirmation before execution, preventing unintended actions and **ensuring complete control over operations and data retrieval**.

### Protect sensitive data from AI exposure automatically
Sensitive information is automatically masked before being processed by AI, including:

- Email addresses  
- Phone numbers  
- User Principal Names (UPN)  
- IP addresses  
- Credit card numbers  
- Dates  
- Postal codes  

### Protect any sensitive information from AI manually

Need additional protection? Wrap any sensitive value in **double quotes**.

**Examples**

- Employee IDs  
- Client names  
- Project codes  
- Internal identifiers  

Anything inside quotes is masked before AI processing, giving you **complete control over what is shared**.

### Dynamic consent

The AdminDroid AI Assistant follows the **principle of least privilege**, requesting permissions only when required based on the query. This ensures you stay in control of access at all times.
