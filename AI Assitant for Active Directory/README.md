## Built with Security in Mind

Active Directory contains highly sensitive organizational data. AdminDroid AI Assistant ensures your information remains protected before it reaches any AI service.

### Automatic Data Masking

Sensitive data is automatically masked before AI processing, including:

- Email addresses  
- Phone numbers  
- User Principal Names (UPN)  
- IP addresses  
- Credit card numbers  
- Sensitive dates  


### Custom Masking for Full Control

For additional protection, simply wrap any sensitive value in **double quotes**.

Examples:

- Employee IDs  
- Client names  
- Project codes  
- Internal identifiers  

Anything inside double quotes will be masked before it reaches AI processing.

This ensures **complete control over what data is shared with AI services**.
